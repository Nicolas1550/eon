GENESIS V1 — AWAKENING | BASADO EN EON V7
=======================================
1. Extraer el ZIP en una carpeta nueva.
2. Abrir PowerShell en la carpeta con package.json.
3. Instalar dependencias y ejecutar:

npm.cmd install
npm.cmd run dev

4. Abrir http://localhost:3000
5. Presionar AWAKEN WORLD, luego el icono de la brújula para enfocar el núcleo.
6. Cambiar ECO / HIGH / ULTRA y observar el FPS. ULTRA no activa CUDA; utiliza WebGL.
7. Para login y guardar ciudades, copiar TU .env.local desde EON. No publicar secretos.
8. No volver a ejecutar SQL: usamos exactamente el esquema de EON.

Para pruebas locales:

npm.cmd run test
npm.cmd run typecheck
npm.cmd run build

Para generar un render con tu RTX 3090 en Blender, leer README.md.
